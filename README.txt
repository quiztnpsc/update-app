Revision Quiz app  (version 2026.11.08)

FIRST TIME (one-time): upload ALL files in this folder to your web host (replace the old files), then close and reopen the installed app once.

HOW TO PUSH A FUTURE UPDATE (no reinstall for students):
1. Replace index.html on your host with the new one, and edit version.json (change "v" to a new number, e.g. 2026.12.01, and optionally "notes").
2. Students open the app: a banner says 'New version available'. They tap 'Update now' (or the 'Check for updates' button at the top). Their logins, answers and scores are kept.

Note: this installed copy stores students/scores on each device. For one shared class list across all devices, use the web link.
